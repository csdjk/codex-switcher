# Windows 动态额度图标验收

日期：2026-09-09。用户确认同时用于任务栏应用图标和右下角通知区域图标。

## 行为

- 两处图标复用同一个原生 RGBA 绘制函数，显示居中的剩余额度数字与圆环进度。
- 只选择当前账号的额度。多个额度窗口同时存在时，显示剩余最少的一项；只有一项时显示该项。
- 大于 30% 为绿色，11%–30% 为黄色，0%–10% 为红色。未知、缺失或查询失败显示灰色 `--`，不会显示为 0%。
- 悬停托盘图标可查看各额度窗口的剩余百分比，以及“取剩余最少的一项”的说明。
- 页面回传额度或原生后台每 60 秒轮询时更新。原生后台轮询在主窗口隐藏后仍运行；账号库变更后重新选取当前账号数据。
- 仅 Windows 改变图标；原有 macOS/Linux 图标逻辑保留。任务栏图标属于正在运行的原生窗口，浏览器预览和未运行时的快捷方式图标不属于动态显示范围。

## 实现

- `src-tauri/src/quota_icon.rs`：额度选择、颜色和 32×32 像素绘制，无新依赖和图片文件。
- `src-tauri/src/tray.rs`：更新主窗口与托盘图标、悬停说明，Windows 后台查询失败时清除旧额度。
- `src-tauri/examples/quota_icon_preview.rs`：独立原生视觉检查程序，依次展示 80%、26%、8%、0%、未知；不读取账号库、不查询网络、不切换真实账号，40 秒后退出。
- `src-tauri/build.rs`：为 Windows 示例程序补齐 Common Controls 6 清单，避免原生示例加载 `TaskDialogIndirect` 时出现入口点缺失。

- 原生截图环境：Windows，桌面 2560×1440，任务栏区域 `(0,1392,2560,48)`，100% 缩放。通过只读 Win32/系统截图接口取图，没有移动鼠标。测试托盘图标被 Windows 收入隐藏区域时，通过 UI Automation 调用“显示隐藏的图标”，截图后收起。

## 2026-09-20 圆环精细化

- 圆环从上一版 3.7px 收细到 2.5px（按 32px 图标计算），使用连续的深石墨色内盘，去掉内圈描边和透明缝隙。
- 高亮弧保留绿色／黄色／红色三档语义，仅在同一色系内作轻微明暗渐变；柔光根据到弧线和圆头的实际距离衰减，不扩大成整圈色晕。
- 端点使用圆头距离场，并补偿圆头对弧长的影响，避免 99% 过早看起来像满圈。0% 不绘制亮弧，使用暗红轨道与红色数字；未知状态显示灰色轨道与 `--`。
- 中心数字优先使用 Windows 原生 Segoe UI 半粗字体，按实际字迹范围居中。两位数使用 13.5px 字号（实际字迹高度约 10px），100 使用 11.75px 字号；比上一版 5×7 像素字更小、更平滑。
- 字形通过 `quota_icon_text.rs` 在私有 GDI 位图中生成灰度覆盖率，再与圆环一起 4× 超采样缩回 32px。只缓存覆盖率，不长期持有 GDI 句柄；字体不可用时回退为较小的内置字形。没有打包或复制系统字体，没有新增 Cargo 依赖。
- `quota_icon_preview --export-dir <目录>` 可直接导出生产绘制函数的 14 种 RGBA 样本，不开启账号界面、不读取账号库、不发网络请求。测试值为 0、1、8、10、11、26、30、31、50、80、93、99、100 和未知。
- `cargo test --locked --lib quota_icon`：7 项通过，新增颜色阈值、数字留白、顺时针方向／99% 缺口、越界输入与透明边缘验证。
- 深浅背景的 16/20/24/32px 缩放预览及前后对比：`Temp/quota-refined-qa/visual-review.png`。这些是渲染样本检查，不等同于完整的 Windows DPI／多显示器验收。

- 当前项目 Debug 原生程序已重新构建并启动；实际任务栏与托盘显示当前额度 92%，原生进程响应正常。实际截图：`Temp/quota-refined-qa/live-taskbar.png`、`live-taskbar-icon.png`、`live-icon.png`。未覆盖安装目录程序，未发布安装包，未切换或修改真实账号。
