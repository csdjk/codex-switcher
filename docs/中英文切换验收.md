# 中英文切换验收

## 功能与范围

- 入口：右上角菜单 → 设置 → 语言，支持简体中文和 English。
- 首次按系统语言选择，支持中文地区变体；手动选择保存在 `codex-switcher-language`。
- 切换立即更新主界面、弹窗、统计区、托盘页面及日期格式，不重新挂载表单。
- 浏览器页面通过 storage 事件同步；桌面窗口及原生菜单通过 `language-changed` 事件同步。
- 存储失败会在设置弹窗中显示错误。原始服务端诊断信息、用户输入及产品名称不作自动翻译。
- 同时修复网页版启动时调用桌面窗口 API 导致的白屏，以及托盘首次加载依赖外部事件的问题。
- 窄屏下账号操作按钮分行、排序栏换行；弹窗限制在视口安全范围并允许滚动。

## 复测

测试命令使用 Node.js 22.6+ 的 TypeScript 类型擦除支持。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test:i18n
pnpm test:reset-credits
pnpm test:desktop-reopen
pnpm exec playwright install chromium
```

终端一：

```sh
pnpm exec vite --host 127.0.0.1 --port 3211 --strictPort
```

终端二：

```sh
pnpm test:i18n-ui
```

可通过 `UI_BASE_URL` 修改本地测试地址。脚本拦截账号 API，仅使用测试数据，不会读取、切换或预热真实账号，也不会执行真实强制关闭操作。

## 文件选择回归修复（2026-09-09）

用户反馈选择 `auth.json` 后仍显示“未选择文件”。`pnpm test:file-picker` 在修改前复现失败：模拟原生文件框先返回窗口焦点，再发送文件选择事件，输入框已从 1 个变为 0 个，选中的文件未显示。

修复后仅由文件输入的 `change` / `cancel` 事件结束选择流程，不再根据窗口焦点推断取消。成功选择会清除旧的“请选择文件”提示，打开文件框失败会在弹窗显示错误。后端 API 不存在时给出明确的 404 说明，避免把选中文件误认为已经导入账号。

- 检查：`pnpm test:file-picker`、`pnpm build` 均通过。
- 运行：Chromium，`http://127.0.0.1:1420/`，DPR 1；桌面 `1000×800`、手机模式 `375×667`。
- 覆盖：焦点先于选择、取消、重复选同一文件、选择后清除校验错误、后端不可用提示、文件框打开失败及清理。
- 实际页面截图：`Temp/file-picker-qa/selection-1000.png`、`Temp/file-picker-qa/selection-375.png`、`Temp/file-picker-qa/backend-unavailable-1000.png`、`Temp/file-picker-qa/backend-unavailable-375.png`；已检查文件名显示、错误换行、面板内边距和按钮对齐。
- 测试仅使用内容为 `{}` 的合成 JSON 文件；未读取或导入用户的真实凭据。Rust 后端未启动，真实账号导入仍未验证。

## 真实账号导入补验（2026-09-09）

用户随后提供本机 `auth.json` 并明确要求实际导入。启动项目的 Rust Web 后端，绑定 `127.0.0.1:3210`，健康接口返回成功；已将内置浏览器切换至该完整服务。原 `1420` 页面是只有前端的 Vite 预览。

- 使用 Chromium 的真实文件选择器上传用户指定文件，导入接口返回 HTTP 200，账号卡片出现，识别为 Pro。
- 导入后直接核对本地账号库，新增记录的凭证与源文件一致，当前账号 ID 未改变。
- 原账号库已有同一账号，因此以临时名称验证新增，随后只删除本次新增的记录。清理后账号库结构与测试前一致，仍为 1 个账号；源文件 SHA-256 未改变。没有切换或预热账号。
- 重复账号测试期间中止自动额度请求，避免测试副本触发 OAuth 凭证刷新；导入与持久化接口均未模拟。清理后在内置浏览器正常加载真实额度及使用统计，已显示 7 天额度和使用趋势。
- 证据：`Temp/real-import-qa/result.json`、`selected-desktop.png`、`imported-desktop.png`。导入截图环境为 Chromium，`1000×800`，DPR 1，地址为 `http://127.0.0.1:3210/`。导入后截图中的 `Failed to fetch` 来自上述主动中止额度查询，不表示导入失败；该截图不作为额度验证证据。
- 文件携带的订阅到期字段显示 2026-08-31；这是导入凭证里的旧字段，不足以认定当前订阅已到期。本次未强制刷新登录凭证核实最新订阅日期。

本次补验覆盖浏览器上传及 Rust 后端真实导入，不等同于 Tauri 原生文件框验收。临时验证脚本仅输出布尔校验结果和非敏感元数据，不将凭证写入验收报告。
