优化账号界面与 Codex 额度查询，加入紧凑账号视图和更及时的刷新。

- 统一浅色、深色的新拟态界面，改善弹窗焦点、窄屏布局和统计数字可读性。
- 额度与订阅同步并行；当前账号优先查询，各账号完成后立即显示；合并主窗口和托盘的重叠查询。
- 实时查询暂时失败时显示明确标记的缓存额度和获取时间；过期窗口不再沿用，缓存不会触发自动或定时预热。
- 按五小时、每周窗口中更紧张的剩余额度排序，缓存及未知状态排在实时结果之后。
- 使用统计展开即加载，并复用近期成功结果；备用账号默认紧凑显示，更多操作可展开。
- 仅保留 Codex 额度查询，移除实验性的 ChatGPT 聊天模式额度查询。
- 修复接口响应日志截断中文或 Emoji 时可能引发异常的问题。

发布前验证：27 项前端单元测试、78 项 Rust 单元测试、前端生产构建及 Rust 编译检查通过；额度、订阅、界面主题、语言、会话管理、文件选择和版本更新提示的隔离浏览器回归通过。界面覆盖桌面与移动视口、中英文和深浅主题。截图与细项见仓库 `docs/额度与账号体验优化验收.md` 和 `docs/新拟态界面设计与验收.md`。

下载时请选择对应系统与架构：Windows x64 推荐 `Windows-x64-setup.exe`；Apple Silicon Mac 选择 `macOS-arm64.dmg`，Intel Mac 选择 `macOS-x64.dmg`；Linux x64 提供 AppImage、deb 和 rpm。

安装前请退出 Codex Switcher。应用继续使用“检查新版本 + 手动下载”；macOS 构建未进行 Apple Developer ID 签名或公证。浏览器测试使用隔离账号数据，不代表真实账号服务可用性或跨平台实机验收。
