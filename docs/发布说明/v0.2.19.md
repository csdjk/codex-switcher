新增 Codex Token 输出速度面板，并修复重复启动时窗口无法打开的问题。

## 新增与改进

- 账号总览下方新增 Token 输出速度面板，显示会话模型、最近有效速度、最近最多 5 次有效响应的加权平均速度、token 数和输出时长。
- 支持自动跟随最近活跃会话，也可固定选择会话；模型切换后清除旧模型读数，避免不同模型和项目的统计混合。
- 本地只读、增量读取近期会话日志；页面隐藏时暂停轮询。测速模块不会发送模型请求、修改 Codex 配置或读取认证密钥文件。
- 兼容新旧用量事件并去重；缺失计时、过短输出窗口和历史读数都有明确标记，不将无效数据显示为实时速度。
- 加入单实例唤醒：重复打开应用时恢复已有窗口，支持最小化、关闭到托盘后重新打开，避免重复创建 WebView。
- 深浅主题、中英文和窄屏布局沿用现有界面风格。

## 测速口径

速度以 `≈ tok/s` 显示，按每次模型响应完成后的日志更新，**不是逐 token 瞬时速度或严格的模型性能基准**。输出 token 包含思考 token，计时不直接包含工具执行间隔，但仍受日志精度和工具参数生成等影响。没有有效样本时显示 `--`。自动选择的会话不代表 Codex 当前前台页签，也不绑定切换器中的当前账号。

- 95 项 Rust 单元测试、31 项前端逻辑测试通过。
- 测速、主题、额度、订阅、语言、会话、文件选择、更新提示共 8 套隔离浏览器回归通过；测速与主题覆盖 48 张深浅色和多视口截图。
- Windows 正式 EXE / MSI 构建通过，安装包和程序版本核对为 0.2.19。
- 本机正式程序验证重复打开、最小化恢复、关闭到托盘后恢复；三项均保持单实例并恢复主窗口。
- 真实 Web 后端接口在独立测试目录验证增量读取、双事件去重和加权平均；原生窗口已确认测速面板显示。

浏览器回归使用隔离测试账号和响应，不代表真实账号服务的全面验收。macOS / Linux 由发布流水线构建，本轮未进行这两个平台的实机交互验收。

## 安装

Windows x64 推荐下载 `Codex-Switcher-v0.2.19-Windows-x64-setup.exe`；另提供 MSI。macOS 请按 Apple Silicon / Intel 选择 arm64 / x64；Linux x64 提供 AppImage、deb、rpm。

升级前请从托盘退出旧版及预览版 Codex Switcher，不必关闭 Codex 本身。旧版尚未具备单实例保护，不能与新版同时运行。应用仍采用“检查新版本 → 前往下载 → 手动安装”，不会自动覆盖安装。macOS 构建未进行 Apple Developer ID 签名或公证。
